# Corporate Exchange

Веб-приложение для быстрой конвертации валют. Конвертер автоматически пересчитывает введённую сумму, показывает текущий демонстрационный курс и отображает динамику валют за последние семь дней.

> Курсы в приложении являются демонстрационными и не предназначены для проведения реальных финансовых операций.

## Возможности

- конвертация между USD, EUR, UZS, RUB и GBP;
- автоматический пересчёт суммы при изменении значения или валюты;
- быстрая смена исходной и целевой валют;
- отображение курсов относительно узбекского сума;
- интерактивный график динамики курса за семь дней;
- проверка введённой суммы;
- адаптивный интерфейс для компьютеров и мобильных устройств;
- резервные курсы для автономной работы;
- возможность подключения собственного API курсов через `window.currencyConverter.applyRates()`.

## Технологии

- HTML5 — структура приложения;
- Tailwind CSS — стилизация и адаптивный интерфейс;
- JavaScript (ES6+) — расчёты, валидация и обновление интерфейса;
- SVG — отрисовка графика динамики курса;
- Intl API — локализованное форматирование чисел и даты.

Проект не требует сборки, установки npm-пакетов или Node.js: вся логика находится в файле `index.html`, а Tailwind CSS загружается через CDN.

## Запуск

### Простой способ

Склонируйте репозиторий или скачайте проект, затем откройте файл `index.html` в браузере.

### Через локальный сервер

Если на компьютере установлен Node.js, запустите статический сервер из папки проекта:

```bash
npx serve .
```

После запуска откройте адрес, который появится в терминале, обычно `http://localhost:3000`.

Также можно использовать встроенный сервер Python:

```bash
python3 -m http.server 8000
```

В этом случае приложение будет доступно по адресу `http://localhost:8000`.

## Подключение API курсов

Приложение использует демонстрационные значения из объекта `fallbackRates`. Для передачи актуальных данных вызовите:

```js
window.currencyConverter.applyRates({
  rates: {
    USD: 1,
    EUR: 0.92,
    UZS: 12850,
    RUB: 91.4,
    GBP: 0.78
  },
  updatedAt: new Date().toISOString()
});
```

Все значения в `rates` должны представлять количество единиц соответствующей валюты за 1 USD.
